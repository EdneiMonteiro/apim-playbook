# APIM Workbook

Workbook editorial para produção colaborativa de um artigo técnico sobre **Azure API Management (APIM)**, estruturado em versões iterativas.

## Estrutura

| Pasta / Arquivo | Conteúdo |
|---|---|
| `artigo-v1.md`, `artigo-v2.md`, `artigo-v3.md` | Versões evolutivas do artigo principal |
| `contribuicoes/` | Aportes técnicos consolidados |
| `revisao/` | Revisões editoriais por versão |

## Fluxo de trabalho

1. Cada contribuição é registrada em `contribuicoes/`.
2. As contribuições são consolidadas em uma nova versão do `artigo-vN.md`.
3. A revisão é registrada em `revisao/`, gerando ajustes para a próxima versão.
